# Restaurant Management System

## Overview
The Restaurant Management System is a comprehensive full-stack application designed to streamline the operations of restaurants. This application helps manage tables, orders, customers, and staff responsibilities efficiently.

## Features
- **User Authentication**: Secure login and registration for both staff and managers.
- **Order Management**: Easily create, update, and manage orders.
- **Table Management**: Overview and management of restaurant tables and their statuses.
- **Customer Management**: Detailed management of customer profiles and order history.
- **Reports**: Generate various reports for management analysis.

## Tech Stack
- **Frontend**: Built using React.js, with a rich user interface and seamless user experience.
- **Backend**: Node.js and Express.js for RESTful API development.
- **Database**: MongoDB for data storage and retrieval.

## Testing Setup
1. **Install Testing Libraries**: Ensure you have the required packages for testing (e.g., Jest for backend, React Testing Library for frontend).
2. **Running Tests**: Use the following commands to run tests:
   - For Backend: `npm test`
   - For Frontend: `npm test` in the `client` directory.

## Running the Application
### Prerequisites
- Node.js (version 14.x or higher)
- MongoDB installed and running

### Backend Setup
1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Start the backend server:
   ```bash
   npm start
   ```

### Frontend Setup
1. Navigate to the frontend directory:
   ```bash
   cd client
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Start the frontend development server:
   ```bash
   npm start
   ```
